# Important Notes

- There are two copies of the Verismart benchmarks

  + The copy `verismart-origin` is the original benchmark, downloaded from the
    GitHub repository: https://github.com/kupl/VeriSmart-benchmarks/

  + The copy `verismart-solidity-0.7.0` is the version where certain test cases
    are migrated to Solidity version 0.7.0 ensure that these smart contracts can
    also be compiled by the 3rd-party [Solang](https://github.com/hyperledger-labs/solang) compiler.

    Note that for `verismart-solidity-0.7.0`, currently, only the sub-benchmark
    `zeus` is updated.
